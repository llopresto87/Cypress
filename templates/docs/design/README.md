# Design

Implementable interface/interaction design specs, authored by
`ui-ux-designer`, each mapping to a spec's §3 (user-facing behavior)
and §9 (acceptance criteria).

- `<feature>.md` — one design spec per deliverable: screen flows,
  interaction states (loading/empty/error/success), components and
  design tokens used, visual hierarchy, and accessibility
  implementation notes (the floor itself is owned by `product`).
- `tokens.md` — the project's design-token and component-system
  reference, kept current as specs extend it.

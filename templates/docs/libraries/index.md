# Libraries index

The wiki of external dependencies used by this project. Each row links
to the project-local wiki page that records the install command, used
API surface, idioms, pitfalls, and citations to upstream sources.

The index is complete against the project's manifests: every direct
dependency they declare has a row here or a row under "Deliberately
without a page". Check it by listing the manifests' direct dependencies
and comparing them with both tables; a dependency in neither is a gap.

# Prompts

Versioned prompts and prompt contracts.

- `prompt-registry.md` — every active prompt, its version, its
  contract file.
- `prompt-contracts/PROMPT-NNNN-<slug>.md` — one contract per active
  prompt, using `templates/prompt-contract.template.md`. The prompt body
  itself lives inline in the contract's §12 (diffable,
  version-controlled); there is no separate prompt-body file.

# Prompts

Versioned prompts and prompt contracts.

- `prompt-registry.md` — every active prompt, its version, its
  contract file.
- `prompt-contracts/PROMPT-NNNN-*.md` — one contract per active
  prompt, using `templates/prompt-contract.template.md`.
- `prompts/PROMPT-NNNN-*.txt` — the prompt bodies themselves
  (diffable, version-controlled).
